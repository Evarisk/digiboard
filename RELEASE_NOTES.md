# [DigiBoard] [23.1.0] - Tickets des instances distantes

Description : Cette version permet de lire les tickets d'autres instances Dolibarr : liste consolidée, tableau de bord, et configuration des instances distantes interrogées.

**Cette version demande Saturne 23.2.0 ou supérieur.**

## Nouvelles fonctionnalités et innovations

### Tickets distants

* Lecture des **tickets d'autres instances Dolibarr**, avec leur liste et leur tableau de bord.
* Page de configuration des instances distantes interrogées.
